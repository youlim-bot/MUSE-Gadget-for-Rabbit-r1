# V2.0 showcase and Discord kit

Real native Android views captured in a disposable 480×640 / density 200 Android 16 emulator. These are **emulator screenshots, not physical R1 captures**. The separate offline demo has no Internet, location, microphone or camera permission and cannot schedule alarms. Conversations, answers, weather, area names, battery, signal and reminders are fictional. Pet ages and care state are simulated for illustration; the main game still progresses over days. The avatar is the owner-provided Muse-generated dolphin.

![V2.0 virtual-pet overview — fictional data and simulated ages](images/discord-overview.png)

[Copy the English Discord post](DISCORD-V2.0.md). Attach `discord-overview.png` and paste the post. Optional: add [three-language pet screens](images/discord-pet-languages.png), [daily tools](images/discord-daily-tools.png) or [clock/reminders](images/discord-clock-reminders.png). Keep the demo disclosure when sharing. The historical V1.5 kit remains attached to its release; images on this branch now show V2.0.
