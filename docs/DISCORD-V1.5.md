**MUSE Gadget for Rabbit r1 — V1.5**

I installed LineageOS and Muse on my Rabbit r1, then customized the app for everyday use. It’s based on Cameron Pak’s muse-r1 project, and I’ve now updated my version to V1.5.

What’s new:
• Interrupt a spoken reply with the side button and start a new question.
• Set alarms, timers and appointment reminders that run on the r1 itself.
• See battery/charging status and upcoming reminders on the home screen.
• Use a charging desk clock with weekday, weather icons, temperature, humidity and hourly UV forecasts.
• Follow the spoken reply as the conversation scrolls, or browse it with the wheel.
• Choose whether the Muse screen stays awake.

It also includes Korean/Japanese/English UI and sentence-by-sentence interpretation, photo questions and text translation, keyboard chat, optional ElevenLabs speech, favorites, search, voice-to-text memos and checklists.

Source code, installation/recovery notes and feature guides are available in English, Korean and Japanese:
https://github.com/youlim-bot/MUSE-Gadget-for-Rabbit-r1

The screenshots show the real Android UI in a separate offline demo, using the original Muse avatar and fictional data—including the weather, location, battery and reminders. They are not live AI results.

This is a community customization, not an official Rabbit or Muse release. Credit to Cameron Pak and the r1 community. Feedback welcome!
