# 復旧と開発の記録

[English](../en/JOURNEY.md) · [한국어](../ko/JOURNEY.md) · [日本語](JOURNEY.md) · [導入ガイド](GUIDE.md)

2026年10月5〜6日に所有者の端末で行った作業を、個人情報を除いてまとめています。上流プロジェクトの過去の検証を、この公開版で新たに実施した検証として扱いません。端末ID、バックアップの場所、生ログ、認証情報、個人写真は掲載しません。

## LineageOS導入前の復旧

1. 元の2025年9月系ファームウェアに5月系 `v0.8.293` のboot/vbmetaが混在した状態でfastbootdに入れませんでした。所有者はdm-verity corruption警告を報告し、その後は無限ループではなく一度起動を試みて電源が切れる状態と説明しました。
2. 端末自身の純正バックアップを端末識別情報・パーティションと照合しました。53件中52件のチェックサムが一致し、不一致の `frp-unlock.bin` は復元対象から除外しました。
3. 元の `boot_a/b`、`vbmeta_a/b`、`vbmeta_system_a/b`、`vbmeta_vendor_a/b` を復元して再読み取りで検証しました。`para` も元に戻して検証しました。
4. `super` 全体を読み取り、バックアップと一致することを確認しました。原因の推測だけでsuperを書き直していません。
5. この端末の認証付きV4 `seccfg` に残ったmanaged-verityエラー状態を調査しました。アンロック状態を保ったまま必要な範囲だけを修正し、認証と全体の再読み取りを検証しました。その後、所有者が純正OSの正常起動を確認しました。
6. 続く導入では `is-userspace: yes`、スロットA、論理 `system_a` を確認しました。確認済みGSI/vbmetaの導入と明示的なuserdata/metadata初期化を実施し、所有者はLineageOS初期設定に到達してMuseをインストール・ペアリングしました。

**汎用的なseccfgパッチではありません。** 任意のオフセットをゼロにしたり、別端末のパーティションをコピーしたり、変更済みブートチェーンを再ロックしたりしないでください。警告だけで同じ原因と断定できません。認証方式・ファームウェア・端末状態の確認が必要なため、修復バイナリーやワンクリック復旧ツールは配布しません。

最初の動画だけで各フレームの起動状態が確定したわけではありません。動画をfastbootdへの移行証拠として扱いません。警告の報告、モード照会、再読み取り、所有者の正常起動確認に基づく記録です。

調査の参考：[ファームウェアガイド](https://github.com/TurboTheTurtle/rabbit-r1-firmware/blob/main/docs/flashing-guide.md)、[mtkclient #306](https://github.com/bkerler/mtkclient/issues/306)、[コミュニティde-verity事例](https://github.com/jonathanprocter/rabbit-r1-deverity-recovery/blob/main/docs/rabbit-r1-de-verity-recovery-community-writeup.md)。自分の端末の確認を省略して実行する手順ではありません。

## 機能追加の流れ

| 段階 | 内容 | 確認範囲・制約 |
|---|---|---|
| 基本アプリ | ホーム、Museペアリング、暗号化認証、サイドボタン、ホイール音量、履歴 | Cameron PakのMITプロジェクトが基盤。プロトコルの出典・ライセンスを保持。 |
| 韓国語音声 | Android韓国語TTS、その後ElevenLabs認識・音声 | 所有者が韓国語出力を確認。音声出力と認識は別処理。 |
| USB・LTE | ケーブル・ポート・デバッグ承認、Rakuten Japanデータ | Wi-Fiを切ってセルラーを確認。通話・SMS・全通信会社は未検証。 |
| 通訳 | 韓・日・英の入力／出力、方向交換、文単位の連続処理 | 同時ストリーミングではない。通訳時だけ言語行を表示。 |
| UI | 小型ボタン、国旗、サイレント、文字サイズ・音声速度 | 実機で設定保存を確認。一部の従来ステータス・エラー文言は未翻訳。 |
| カメラ | 前面／背面、撮影・確認・保存、写真質問・文字翻訳・追加質問 | カメラ選択による実回転を確認。ホイールとライブ画像回答は追加確認が必要。 |
| キーボード・アバター | Android IME、個人画像、サイズ調整 | 韓・日・英IME選択を設定。アカウント画像の自動同期は未実装。V2.0は所有者提供のイルカを使用（以前の公開版は標準アバター）。 |
| ライブラリ | お気に入り、ローカル検索、音声メモ | 録音は最大20秒、保存は文字であり音声アーカイブではない。 |
| タスク・設定 | 抽出結果確認、チェックリスト、18〜26sp・0.75〜1.5倍 | テスト・設定保存を確認。抽出品質や聴感の比較はユーザーテストが必要。 |

機能APKはJVMテスト67件に合格し、暗号化認証情報を維持して更新しました。認識品質、画像回答、物理ホイール、電池・通信障害の試験を代替するものではありません。[公開版の検証](../development.md#public-export-checks)は別途記録します。

## V2.0公開

育成画面、ローカルBGM・効果音、設定整理、UV表示改善、接続復旧の変更を公開ソースに含めました。画像は独立したAndroidエミュレーターで架空データを使って新たに撮影したもので、R1の実際のネットワーク応答の検証ではありません。[V2.0ノート](../RELEASE-V2.0.md)をご覧ください。
