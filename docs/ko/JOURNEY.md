# 복구 및 개발 기록

[English](../en/JOURNEY.md) · [한국어](JOURNEY.md) · [日本語](../ja/JOURNEY.md) · [설치 가이드](GUIDE.md)

2026년 10월 5~6일 사용자 기기에서 진행한 작업을 개인정보 없이 정리했습니다. 원본 프로젝트의 과거 검증을 이 공개판에서 새로 실시한 것으로 표현하지 않습니다. 기기 ID, 백업 경로, 원시 로그, 인증 정보, 개인 사진은 제외했습니다.

## LineageOS 설치 전 복구

1. 원래 2025년 9월 계열 펌웨어에 5월 계열 `v0.8.293` boot/vbmeta를 섞은 뒤 fastbootd 진입이 실패했습니다. 사용자는 dm-verity corruption 경고를 보고했고, 이후에는 무한 반복이 아니라 한 번 부팅 시도 후 꺼진다고 설명했습니다.
2. 본인 기기의 원본 백업을 기기 식별값·파티션과 대조했습니다. 체크섬 53개 중 52개가 일치했고, 불일치한 `frp-unlock.bin`은 복원에서 제외했습니다.
3. 원본 `boot_a/b`, `vbmeta_a/b`, `vbmeta_system_a/b`, `vbmeta_vendor_a/b`를 복원하고 재읽기로 확인했습니다. `para`도 원본으로 복원·검증했습니다.
4. `super` 전체를 읽어 백업과 일치함을 확인했습니다. 원인을 추측하기 위해 super를 다시 쓰지 않았습니다.
5. 이 기기의 인증된 V4 `seccfg`에 남아 있던 managed-verity 오류 상태를 조사했습니다. 언락 상태를 유지하면서 필요한 범위만 수정하고 인증 및 전체 재읽기를 검증했습니다. 이후 사용자가 정상 순정 부팅을 확인했습니다.
6. 다음 설치 단계에서는 `is-userspace: yes`, 슬롯 A, 논리 `system_a`를 확인했습니다. 검증한 GSI/vbmeta 설치와 명시적인 userdata/metadata 초기화를 완료했고, 사용자는 LineageOS 초기 설정에 진입한 뒤 Muse를 설치·페어링했습니다.

**누구에게나 적용되는 seccfg 패치가 아닙니다.** 임의 오프셋을 0으로 바꾸거나 다른 기기의 파티션을 복사하거나 수정된 부트 체인을 다시 잠그지 마세요. 경고 화면만으로 같은 원인을 단정하지 않습니다. 인증 방식·펌웨어·기기 상태를 확인해야 하므로 복구 바이너리나 원클릭 복구 도구는 배포하지 않습니다.

처음 제출된 영상만으로 프레임별 부팅 상태가 확정된 것은 아닙니다. 영상을 fastbootd 진입 증거로 사용하지 않습니다. 경고 보고, 모드 질의, 재읽기, 사용자의 정상 부팅 확인을 근거로 범위를 한정합니다.

조사 참고: [펌웨어 가이드](https://github.com/TurboTheTurtle/rabbit-r1-firmware/blob/main/docs/flashing-guide.md), [mtkclient #306](https://github.com/bkerler/mtkclient/issues/306), [커뮤니티 de-verity 사례](https://github.com/jonathanprocter/rabbit-r1-deverity-recovery/blob/main/docs/rabbit-r1-de-verity-recovery-community-writeup.md). 본인 기기의 확인을 대신하는 자동 실행 절차가 아닙니다.

## 기능 추가 흐름

| 단계 | 추가·변경 내용 | 확인 범위와 한계 |
|---|---|---|
| 기본 앱 | 홈 앱, Muse 페어링, 암호화 인증, 측면 버튼, 휠 볼륨, 기록 | Cameron Pak의 MIT 프로젝트 기반. 프로토콜 출처·라이선스 유지. |
| 한국어 음성 | Android 한국어 TTS, 이후 ElevenLabs 인식·출력 | 사용자가 한국어 출력을 확인. 출력과 인식은 별개. |
| USB·LTE | 케이블·포트·디버깅 승인, 일본 Rakuten 데이터 | Wi-Fi를 끄고 셀룰러 연결 확인. 통화·SMS·다른 통신사는 검증하지 않음. |
| 통역 | 한·일·영 입력·대상, 방향 교환, 문장 단위 연속 처리 | 동시 스트리밍 아님. 통역에서만 언어 줄 표시. |
| 인터페이스 | 작은 버튼, 국기, 조용한 모드, 글자 크기·음성 속도 | 설정 저장을 실기기에서 확인. 일부 기존 상태·오류 문구는 번역이 남아 있음. |
| 카메라 | 전면/후면, 촬영·확인·저장, 사진 질문·글자 번역·후속 질문 | 카메라 선택에 따른 실제 회전 확인. 휠 및 실시간 사진 답변은 추가 확인 필요. |
| 키보드·아바타 | Android IME, 개인 이미지, 크기 조정 | 기기에서 한·일·영 키보드 선택 확인. 계정 아바타 자동 동기화는 미구현. 공개판은 원본 Muse r1 기본 아바타 사용. |
| 보관함 | 즐겨찾기, 로컬 검색, 음성 메모 | 녹음 최대 20초, 저장물은 텍스트이며 음성 보관함이 아님. |
| 할 일·설정 | 메모 추출 결과 검토, 체크리스트, 18~26sp·0.75~1.5배 | 테스트·설정 저장 확인. 실제 할 일 추출 품질과 음성 청감 비교는 사용자 시험 필요. |

기능 APK는 JVM 테스트 67개를 통과하고 암호화 인증 정보를 유지하여 업데이트했습니다. 인식 품질, 사진 답변, 물리 휠, 배터리·네트워크 실패 시험을 대신하지 않습니다. [공개판 검증](../development.md#public-export-checks)은 별도로 기록합니다.
